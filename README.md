Problem Statement:
Elevations of points can be established through leveling fieldwork operation referred from known elevations (e.g. benchmark).

Level loops that start and end at the same benchmark can be checked for misclosure, which can be compared to the allowable errors depending on target order of accuracy.

Objective:

Develop a Python program that:

1. Reads leveling data from csv file.
➢ The program should be able to handle either 3-wire leveling data or differential leveling data.
2. Implements differential leveling computation to determine the elevations of points.
3. Computes the misclosure and evaluates the order of accuracy achieved.
4. Applies the formula for deriving the adjusted elevation of points.
5. Outputs a report of the leveling computation in formatted table.
6. Outputs a report of the misclosure and accuracy

Dataset: leveling_data.csv and leveling3wire_data.csv

Required Outputs:
▪ Formatted report of the computations and final values, saved as text file or html file.
